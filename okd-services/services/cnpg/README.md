# CloudNative-PG (CNPG)

Operator for PostgreSQL clusters on OKD.

- Chart: `cloudnative-pg`
- Repo: `https://cloudnative-pg.github.io/charts`
- Namespace: `cnpg-system`
- Version: `0.29.0`

## Managed Clusters

- `authentik/authentik-pg`: 2 instances (HA, async streaming replication), using `local-path-retain` storage class.
